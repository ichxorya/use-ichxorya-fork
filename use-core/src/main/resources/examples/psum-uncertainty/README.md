# PSUM Uncertainty Examples

This directory contains examples of models that utilize the uncertainty datatypes.

## Uncertainty.use

This model comes from the REPLICATION PACKAGE for the paper "Uncertainty-aware consistency checking in industrial settings" published at MODELS 2023.
**Authors**: Robbert Jongeling and Antonio Vallecillo

This model thoroughly tests the SBoolean types and custom operators like fusion (`WBF`, `ABF`), `implies`, `and`, and `.belief()`. You can load this file directly in the custom USE 7.5.0 build to verify the parsing of the `SBoolean(b,d,u,br)` literals and type evaluation.
